# 🚗 Анализ ДТП Республики Ингушетия (2015-2025)

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![Pandas](https://img.shields.io/badge/Pandas-2.0+-green.svg)](https://pandas.pydata.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> Комплексный анализ дорожно-транспортных происшествий с применением статистических методов, машинного обучения и геопространственного анализа.

![Header Image](assets/header-image.png)

## 📊 Ключевые результаты

- **2 155 ДТП** проанализировано за 10,5 лет
- **683 погибших**, 3 546 раненых
- **74,4% ДТП** классифицируются как тяжёлые или с погибшими
- **5 критических зон** с максимальной концентрацией аварий выявлено
- **54% снижение смертности** в период религиозных праздников (неожиданная находка!)

## 🎯 Цель проекта

Предоставить администрации Республики Ингушетия **научно-обоснованные рекомендации** для снижения аварийности на основе комплексного анализа факторов риска.

## 📈 Методология

### 1. Сбор и подготовка данных

- **Источник**: dtp-stat.ru (официальная статистика ГИБДД)
- **Период**: 01.01.2015 - 29.06.2025
- **Формат**: GeoJSON с детальной информацией о каждом ДТП
- **Геолокация**: 90,5% ДТП имеют координаты

### 2. Методы анализа

#### Статистический анализ
- Описательная статистика
- Корреляционный анализ
- Тестирование гипотез (Chi-square, t-tests)

#### Пространственный анализ
- **DBSCAN кластеризация** для выявления очагов аварийности
- Анализ близости к социальным объектам (школы, больницы)
- Тепловые карты концентрации ДТП

#### Временной анализ
- Почасовое распределение аварий
- Анализ по дням недели
- Сезонные паттерны
- Влияние религиозных праздников (Ид аль-Фитр)

#### Социально-культурные факторы
- Воскресные свадьбы (традиция региона)
- Религиозные праздники
- Миграция населения в праздничные дни

### 3. Инструменты

- **Python**: pandas, numpy, scikit-learn
- **Визуализация**: matplotlib, seaborn, plotly, Leaflet.js
- **Геоанализ**: geopandas, folium
- **Отчётность**: python-docx, openpyxl

### Социально-культурные факторы

#### 🕌 Ид аль-Фитр (Ураза-байрам)
**Неожиданное открытие**: Вопреки гипотезе, смертность в период праздника **снижается на 54%**!

- Период праздника (3 дня): 0,147 погибших на ДТП
- Остальные дни: 0,320 погибших на ДТП

**Объяснение**: 
- Религиозный контекст → осмотрительное поведение
- Семейные празднования дома
- Массовые поездки происходят **ЗА 2-3 ДНЯ ДО** праздника

**Расширенный период (±3 дня)**: рост смертности на +11,2% подтверждает гипотезу!

#### 💒 Воскресные свадьбы
- Традиция проведения свадеб по воскресеньям
- Рост смертности на **26%** (0,39 vs 0,31 в будни)
- Свадебные кортежи + алкоголь + рискованное вождение

## 🎯 Рекомендации для администрации

### Приоритет 1: Инфраструктурные меры (краткосрочные)

✅ **Установка освещения** на 5 критических участках
- Потенциальное снижение смертности: 15-20%
- Стоимость: умеренная
- Эффект: немедленный

✅ **Искусственные неровности** у школ/больниц
- Снижение скорости на 20-30%
- Стоимость: низкая
- Эффект: высокий

✅ **Восстановление разметки** на участках с высокой концентрацией ДТП

### Приоритет 2: Организационные меры

✅ **Усиление патрулирования**
- Воскресенья 16:00-23:00 (свадьбы)
- За 2-3 дня до Ид аль-Фитр (пик поездок)
- Вечернее время (16:00-23:00)

✅ **Регулирование свадебных кортежей**
- Требования по сопровождению
- Ограничения скорости
- Запрет рискованных маневров

### Приоритет 3: Профилактические меры

✅ **Работа с религиозными лидерами**
- Проповеди о безопасности перед праздниками
- Охват: 90%+ населения

✅ **Информационные кампании**
- Молодые водители (основная группа риска)
- Использование ремней безопасности
- Опасность вождения в состоянии опьянения

### Приоритет 4: Аналитические меры

✅ **Онлайн-дашборд аварийности**
- Мониторинг в реальном времени
- Выявление новых очагов
- Оценка эффективности мер

✅ **Ежеквартальные отчёты** для руководства региона
