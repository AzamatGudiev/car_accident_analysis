# Jupyter Notebooks

Последовательность выполнения:

## 1️⃣ Базовый анализ
- `01_data_exploration.ipynb` — загрузка и первичный анализ данных
- `02_temporal_analysis.ipynb` — временные паттерны (часы, дни недели)

## 2️⃣ Пространственный анализ
- `03_spatial_clustering.ipynb` — DBSCAN кластеризация, очаги аварийности

## 3️⃣ Специализированный анализ
- `04_cultural_factors.ipynb` — религиозные праздники, воскресные свадьбы
- `05_visualization.ipynb` — создание интерактивных карт

## Как использовать

```bash
# Запустить Jupyter Lab
jupyter lab

# Выполнять ноутбуки последовательно
# Каждый ноутбук сохраняет промежуточные результаты в data/processed/
```

## Требования

- Python 3.8+
- Установленные зависимости из `requirements.txt`
- Данные в `data/raw/respublika-ingushetiia_2.geojson`

## Результаты

После выполнения всех ноутбуков в `outputs/` появятся:
- Интерактивные карты (HTML)
- Графики (PNG)
- Отчёт (DOCX)
