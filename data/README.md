## Исходные данные

### respublika-ingushetiia_2.geojson

**Описание**: Полный датасет ДТП в Республике Ингушетия  
**Источник**: https://dtp-stat.ru/  
**Период**: 01.01.2015 - 29.06.2025  
**Размер**: ~3.8 MB  
**Формат**: GeoJSON с вложенной структурой  

**Структура данных**:
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [44.747154, 43.525565]
      },
      "properties": {
        "id": 41034,
        "datetime": "2019-12-26 18:00:00",
        "severity": "Легкий",
        "category": "Опрокидывание",
        "dead_count": 0,
        "injured_count": 2,
        "light": "В темное время суток, освещение отсутствует",
        "weather": ["Туман"],
        "road_conditions": ["Сухое"],
        "vehicles": [...],
        "participants": [...]
      }
    }
  ]
}
```

**Ключевые поля**:
- `id`: Уникальный идентификатор ДТП
- `datetime`: Дата и время происшествия
- `severity`: Тяжесть (Легкий, Тяжёлый, С погибшими)
- `category`: Тип ДТП (Столкновение, Наезд на пешехода и т.д.)
- `dead_count`: Количество погибших
- `injured_count`: Количество раненых
- `coordinates`: [longitude, latitude]

## Словарь данных

### Категории тяжести (severity)
- **Легкий**: Только лёгкие травмы, амбулаторное лечение
- **Тяжёлый**: Госпитализация, стационарное лечение
- **С погибшими**: Один или более погибших

### Типы ДТП (category)
- **Столкновение**: Столкновение транспортных средств
- **Наезд на пешехода**: ТС сбило пешехода
- **Наезд на препятствие**: ТС врезалось в неподвижный объект
- **Съезд с дороги**: ТС покинуло проезжую часть
- **Опрокидывание**: ТС перевернулось
- **Наезд на стоящее ТС**: Столкновение с припаркованным авто
- **Наезд на животное**: ТС сбило животное
- **Наезд на велосипедиста**: ТС сбило велосипедиста

### Условия освещённости (light)
- **Светлое время суток**
- **В темное время суток, освещение включено**
- **В темное время суток, освещение отсутствует**
- **В темное время суток, освещение не включено**
- **Сумерки**

### Погодные условия (weather)
- **Ясно**
- **Пасмурно**
- **Дождь**
- **Туман**
- **Снегопад**
